- [ ] Browser/profile contains no email, calendar, bookmarks, or private tabs.
- [ ] Password manager and desktop notifications are disabled.
- [ ] API keys and authorization headers cannot appear.
- [ ] Terminal prompt and paths reveal no unnecessary personal data.
